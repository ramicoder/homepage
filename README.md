# Rami Daood - Simple Portfolio 

A responsive, custom-built personal portfolio website showcasing my software engineering and full-stack development projects. Built from scratch to demonstrate advanced CSS layouts, responsive design, and semantic HTML.

[**View Live Site**](https://ramicoder.github.io/homepage/) 

## Features
- **Fully Responsive:** Fluid layouts adapting seamlessly across mobile, tablet, and desktop viewports (320px to 1920px+).
- **Modern Layouts:** Heavy utilization of CSS Grid and Flexbox for complex, overlapping element positioning (e.g., text wrapping around absolute images).
- **Accessible Design:** Implements semantic HTML5 tags (`<header>`, `<main>`, `<footer>`) and ARIA labels for screen reader compatibility.
- **Performance:** Pure HTML and CSS with lightweight, scalable inline SVGs.

## Technologies Used
- HTML5
- CSS3 (Grid, Flexbox, Media Queries, Custom Properties)
- Google Fonts (Playfair Display, Roboto)

## Featured Projects
- **Finance:** Virtual stock portfolio manager.
- **Battleship:** Classic web-based game built with vanilla JavaScript.
- **Heritage Site Scheduling System:** Java-based booking application.
- **BJJ Gym Database Design:** Database system for martial arts gym management.
- **Workspace Manager:** Vanilla JS task management application.
- **Admin Dashboard:** UI/UX admin interface focusing on CSS Grid.
